# Alignerr project description

**Project name:** ADF LAB — Automotive Embedded Research Bench
**Domain:** Local engineering applications, embedded software research, validation
**Code:** Python, JavaScript, HTML/CSS, C166-style restricted interpreter

## English application text
I am developing ADF LAB, a local engineering application for automotive embedded-systems research. It combines a Python backend, a JavaScript dashboard, a structured test matrix and independent regression models for constrained control-state logic. I use AI coding assistance to prototype and review software, then check the results against deterministic tests and explicit engineering constraints. I separate reproducible offline results from unverified ECU hardware behavior. The repository contains source code and an anonymized demo state, excluding original manufacturer firmware and private measurements.

## Texto en español
Desarrollo ADF LAB, una aplicación local para investigar software embebido del automóvil. Integra backend Python, panel JavaScript, matrices de pruebas y modelos independientes con verificaciones reproducibles. Utilizo asistentes de programación con IA y evalúo sus resultados mediante pruebas y análisis de sus limitaciones. Distingo entre software validado en PC e hipótesis sobre la ejecución en una ECU real. La versión destinada a GitHub excluye firmware original y mediciones privadas.
