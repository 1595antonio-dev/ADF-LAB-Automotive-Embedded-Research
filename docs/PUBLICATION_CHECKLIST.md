# Pre-publication checklist

- [x] Staging folder created; source project unmodified.
- [x] Firmware and calibration files excluded.
- [x] Raw diagnostic logs, physical measurements and device serials excluded.
- [x] Public state explicitly labeled demonstration and anonymized.
- [x] Reference model tests bundled separately from firmware.
- [x] Run all validation commands on staged folder (5 public tests and 23 reference tests).
- [ ] Owner confirms authorship and distribution rights for every file.
- [ ] Owner connects GitHub and chooses public/private visibility.
- [ ] Install or locate Git; create genuine commits, do not forge history.
- [ ] Upload only after explicit approval.
